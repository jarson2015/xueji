# 更多 / 学生管理 · UX 布局 P2 开发计划

承接全站布局规划中，今日（P0）与任务清单（P1）之后的 **低频入口整理**。  
原则：**分组降低扫描成本；日常管孩子优先于管协作账号；可选功能不抢首屏**。

状态：**已落地**（2026-07-14）

---

## 为何是 P2

| 因素 | 说明 |
|------|------|
| 心智 | 「更多」是杂物抽屉；无分组时 8～10 张同级卡会淹没高频入口 |
| 频率 | 学生管理日常动作 = 复制登录码 / 帮孩子进入；协家长配置远低于管孩子 |
| 科学 | 分类导航（IA）+ 折叠低频块；每组入口宜 ≤3，避免菜单过载（Hick 定律） |

---

## 信息层级

### 家长 · 更多

```
页头 + 一句引导
→ 【激励】愿望
→ 【回顾】周报 / 周末小会 / 成长
→ 【约定】休息与约定 / 公约 /「零花钱与积分约定」折叠
→ 【其它】归档 / 客厅仪式屏
```

### 学生 · 更多

```
页头 + 一句引导
→ 【计划】我的计划 / 任务档案
→ 【家庭】公约 / 周末小会 / 成长
→ 【可选】零花钱 / 积分约定
→ 【其它】已放下的任务
```

### 家长 · 学生管理

```
页头 + 添加
→ 【主】孩子卡片（登录码 / 进入今日）
→ 【次】家庭协作（默认折叠；有待用邀请码时展开）
```
