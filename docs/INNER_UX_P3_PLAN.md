# 愿望 / 周报 / 约定页内 · UX 布局 P3 开发计划

承接全站布局规划中，更多入口（P2）之后的 **页内信息架构**。  
原则：**看见努力与清单优先；操作区紧凑；策略预设先于细则开关；钱与积分愿望隔离**。

状态：**已落地**（2026-07-14）

---

## 为何是 P3

| 因素 | 说明 |
|------|------|
| 路径 | 从「更多」进入后停留长，配置/复盘页仍是瀑布堆叠 |
| 风险 | 周报被叙事卡淹没可视化；愿望页历史占屏；休息页是设置倾销 |
| 科学 | 扫读页：标题 → 视觉摘要 → 明细折叠；配置页：预设卡片 → 例外 → 高级 |

---

## 信息层级（落地后）

### 家长愿望
```
页头 → 短 lead → 待审定/待兑现 → 愿望清单 → 兑换记录(折叠) → FAB
```

### 学生愿望
```
lead → 小目标 → 余额一行 → 待确认收到(若有) → 商店 → 兑换/流水(折叠) → FAB 提案
```

### 周报
```
headline → 结算横幅 → 心情词 → 热力 → stats → 高光分栏 → 本周细节(折叠)
```

### 休息与约定
```
页头 → 教育策略包 → 休息日政策 → 进阶例外(折叠) → 零花钱/约定开关+细则折叠 → 保存
```
