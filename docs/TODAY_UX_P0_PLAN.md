# 学生今日待办 · UX 布局 P0 开发计划

承接全站布局规划中的 **最高频学生路径**。  
原则对齐家长看板 P0：**行动优先；横幅不挡「下一件」；家庭消息可折叠**。

状态：**已落地**（2026-07-14）

---

## 为何是 P0

| 因素 | 说明 |
|------|------|
| 频率 | 学生端每日主入口 `/student/today` |
| 风险 | 首屏 softNudge / 鼓励 / 家庭消息 / 周目标把「下一件」挤到第二屏 |
| 教育 | 执行意图要求：**一次只做一件**；首屏必须是那一件 |

---

## 信息层级（P0 后）

```
页头（今日 + 连续节奏）
→ 【可行动】修复式退回（再商量）— 仅此可挡在「下一件」前
→ 【P0】下一件 Hero + 吸底 CTA
→ 休息日提示（有下一件时）/ 本周小目标（少年）
→ 家庭消息折叠（鼓励 / softNudge / 轮值 / 补进度 / …）
→ 这一段列表
```

---

## 总览

| ID | 项 | 状态 | 说明 |

| **P0.1** | 「下一件」紧接页头 | ✅ | Hero / 空态紧接 repair 之后 |

| 端 | 期望 |

| TV | 不改复杂逻辑；Hero 大标题仍靠前即可 |

---

## 总验收

- [x] 无紧急退回时，手机打开今日首屏可见「下一件」卡（无需滚过鼓励/周目标）
- [x] 鼓励与 softNudge 在「家庭消息」内，不单独占满宽卡于 Hero 前
- [x] 有补进度时家庭消息仍自动展开
- [x] `npm run build`（apps/web）通过
