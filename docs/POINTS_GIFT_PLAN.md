# 积分赠予（D 方案）· 规格与开发计划

状态：**G0–G5 已全部落地**

确认默认（2026-07-12）：

| 项 | 取值 |
|----|------|
| 存储 | 独立表 `point_gifts`（不污染 `point_pacts`） |
| 扣分时机 | **接收方收下时**转移积分；发起不冻结 |
| 家长闸 | 同意只到 `pending`，**≠ 入账**；仍需对方收下 |
| 限额 | 单笔 **20** / 家长闸 **≥10** / 日发起 **1** / 周净送出 **40** |
| 总开关 | 与约定共用 `pointsPactEnabled`；`young` 整块禁止 |

---

## 语义

- **借用**：有还回日、逾期补分、`PACT_*` 流水  
- **赠予**：无还回、不可讨回、`GIFT_OUT` / `GIFT_IN`  
- 有未还约定不阻止赠予；UI 软提醒（G3）；禁止「受赠一键还约」

## 状态机

`parent_pending` →（家长同意）→ `pending` →（收下）→ `completed` + 积分转移  
任意未完成 → `cancelled`（婉拒 / 发起人取消 / 家长拒绝或取消）

## 验收清单

- [x] 关总开关 / young：赠予入口不可用  
- [x] 双模式文案不混淆；赠予无还回日；禁用「转账/红包/打款」口吻  
- [x] 小额：发起 → 对方收下 → 双方余额与 `GIFT_*` 流水正确  
- [x] 大额：家长同意后仍待收下；拒绝后无流水  
- [x] 对方婉拒 / 发起人取消：无流水  
- [x] 超单笔 / 超日次 / 超周额度：明确错误  
- [x] 收下时余额不足：失败提示  
- [x] 约定页可配置赠予限额；家长可监督家长闸  
- [x] 监控：近 14 天同向多次赠予出现软提示（≥3 次）  
- [x] 打包说明含迁移 0020  

## 文案原则（G5）

- 用：心意、分享、祝贺、帮一把、先缓缓  
- 不用：转账、红包、打款、利息、无偿借款、买免做
