# 教育向动机优化开发计划

依据儿童心理/教育审计：把价值观落到**默认体验**。原则：**P0 文案与默认值优先，再动数据模型**。

状态：**已落地（P0 + P1 + P2）**。P2 执行拆解见 [`EDU_MOTIVATION_P2_PLAN.md`](./EDU_MOTIVATION_P2_PLAN.md)。

---

## P0 — 文案 / 默认值（无大迁移或仅小改）

| ID | 项 | 落地 | 理由 |
|----|-----|------|------|
| P0.1 | 庆祝：过程优先 | `CheckinCelebrate.vue`：主文案在上；积分弱化；无分时说明「先庆祝」 | 防「为分而做」 |
| P0.2 | 连胜→节奏 | 今日页标签、习惯 meta、庆祝 meta 改节奏叙事 | 降断签羞耻 |
| P0.3 | 愿望「托管」 | `RewardsView` 提交/确认文案 | 降惩罚感 |
| P0.4 | 淡出建议更早 + 一键应用 | `buildRewardFadeHint` 阈值降至约 7 天；监控/约定页一键切 `random` | 默认仍 always，但更快引导淡出 |
| P0.5 | 确认闸劝阻 | 家务/习惯开确认时强提示；模板保持默认关 | 保护完成闭环 |
| P0.6 | 轮值/公平文案 | 学生轮值横幅、家长公平提示偏「行动」少点名羞辱 | 手足公平 |
| P0.7 | 引导补强 | 家长/学生 onboarding 文案：少任务、少确认、缓做/休息 | 首因效应 |

**非目标（P0）**：改积分结算公式、强制改默认 `rewardMode`、新建表。

## P1 — 结构默认 + per-child ageBand

| ID | 项 | 落地 | 理由 |
|----|-----|------|------|
| P1.1 | 多孩家务默认建议轮值 | 发布表单：共享+≥2 学生时默认勾选轮值；模板批量同理 | 结构减包办 |
| P1.2 | 监控去比较化 | 弱化并排进度条百分比；突出「还可以一起完成」 | 降社会比较 |
| P1.3 | 低龄护栏 | `young`：积分约定默认不可开或更强警告（已有部分，对齐） | 防金融化 |
| P1.4 | **per-child `ageBand`** | 迁移 `users.age_band`；学生 CRUD；策略读取优先学生级，回落家庭级 | 混龄家庭 |

## 验收

- 学生打卡庆祝：先看见完成叙事，积分不抢主视觉
- 今日不强调「连续 N 天断签归零」口吻
- 愿望页无「扣分惩罚」感
- 监控可一键应用淡出建议
- 多孩发布共享家务时轮值易开
- 可为每个孩子设不同年龄段，今日可见条数/庆祝调性按该孩生效
