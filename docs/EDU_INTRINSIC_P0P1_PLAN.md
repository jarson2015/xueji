# 学生端内驱力提升 · P0–P1 计划

依据：自我决定理论（自主 / 胜任 / 归属）+ 真实使用场景。  
原则：**少造表、前端与文案优先；能复用已有事件/字段则不迁库。**

状态：**已落地（P0 + P1）**

---

## P0 — 低成本、高教育杠杆

| ID | 项 | 落地位置 | 验收 |
|----|-----|----------|------|
| **P0.1** | 打卡后轻量反思芯片（默认可见，可不选） | `TodayView` 打卡抽屉；芯片写入 `reflection` | 打开打卡即见 3 个芯片；可不选直接确认；仍可折叠写自由句 |
| **P0.2** | 庆祝增加 1 条过程/成长句 | `lifecycle` 生成 `growthHint`；`CheckinCelebrate` 展示 | 完成庆祝在积分之上可见成长句（如「今天没用缓做就做完」） |
| **P0.3** | 今日非紧急条幅折叠；休息日少推愿望 | `TodayView` | 非紧急家庭消息默认折叠；休息日空状态不以「看奖励」为主 CTA |

---

## P1 — 结构自主与归属

| ID | 项 | 落地位置 | 验收 |
|----|-----|----------|------|
| **P1.1** | 时段内有限「先做这件」+ 积极缓做文案 | `TodayView` localStorage 排序；缓做 SoftPrompt 文案 | 这一段列表可「先做这件」（每日有限次）；缓做文案偏「照顾节奏」非逃避 |
| **P1.2** | 确认通过 → 学生可见家长短鼓励 | 强化 `checkin:confirmed` 条；今日 API `latestEncouragement` | 有家长留言/点赞时顶栏暖提示；今日页可看到最近一句鼓励 |
| **P1.3** | 愿望/余额视觉降权 | `RewardsView` | 首屏弱化大余额；引导语偏体验/陪伴；物品/金手指不抢首焦 |

---

## 非目标（本轮不做）

- 兴趣任务新字段 / 星星替代积分（可进 P2）
- 后端任务全局排序字段迁移
- 改积分结算公式或强制 `rewardMode`

---

2. P0.1 → P0.2 → P0.3  
3. P1.1 → P1.2 → P1.3  
4. 更新本文档验收勾选
