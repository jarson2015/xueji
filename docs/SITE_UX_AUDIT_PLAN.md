## 2. 页面可达性（功能是否「能进」）

在「手机底栏 ∪ 更多」口径下，业务页均可到达。  
缺口在于断点误判，不是路由缺失。

| 断点 | 家长导航 | 风险 |
|------|----------|------|
| phone &lt;768 | 底栏：看板/任务/学生/更多 | 正常 |
| tablet/desktop 768–1599 | 侧栏含任务+学生 | 正常；P6 双栏可生效 |
| **≥1600 → `isTv`** | 顶栏仅：看板 / 仪式屏 / **更多**；更多页**无**任务、学生入口 | **大屏家长难进任务/学生**；看板点任务在 TV 直接禁用 |

学生 ≥1600 同理收成「今日+愿望」，属 P4 设计；大桌面学生补进度/约定需主动缩窗口或改断点语义。

## 3. 问题清单（对照分析 → 方案与理由）

### P0 · 应优先修

#### P0.1 宽屏误判为 TV，导航死端

- **现象**：外接显示器/笔记本全屏常见 ≥1600；家长从导航进不了「任务清单」「学生管理」；看板 TV 化，无动态/洞察双栏。  
- **根因**：`useBreakpoint` 把 `≥1600` 定为 `tv`；`ParentLayout` TV 壳只留三入口；`MoreView` 未补任务/学生；`MonitorView` 在 `isTv` 下禁用任务点击与家庭动态栏。  
- **方案 A（推荐）**：引入「真实电视」判定（如 `?tv=1`、手动开关、或 `min(width,height)` + 粗指针），**默认宽屏走 desktop 壳**；仅仪式屏/显式 TV 模式收口。  
- **方案 B（最小改动）**：`MoreView` 补「任务清单」「学生管理」；TV 看板允许「去任务」深链；`useMonitorSplit` 在宽屏 desktop 语义下启用。  
- **理由**：P4 目标是客厅远距，不是惩罚大显示器办公家长；否则「有学生却无法从看板操作」会被当成功能坏了。

#### P0.2 Monitor soft/lite 刷新清空洞察

- **现象**：WS/轮询 soft 刷新后，公平提示、教练洞察等消失；右栏洞察闪没。  
- **根因**：`requestLoad(true)` → `?lite=1`；后端 lite 返回 `coachInsights: []`、`fairnessHint: null`；前端 `??`/`=` 用不空数组/`null` 覆盖旧值。  
- **方案**：前端 lite 合并时：对 `coachInsights`/`fairnessHint`/`giftFairnessHint`/`parentOverloadHint` 等，**仅当 full 字段存在且非「空哨兵」时更新**；或 lite 响应省略这些字段（不返回 `[]`/`null`）。  
- **理由**：lite 本意为减负，不应假阴性清洞察。

#### P0.3 看板接口失败 ↔「还没有孩子」空态混淆（对应当前你测到的现象）

- **现象**：学生管理有娃，看板显示「去添加孩子」。  
- **根因（代码层面）**：`children` 初值 `[]`；`loadOnce` 失败只 toast，仍 `loading=false` → 空态条件 `!monitor.children.length` 成立。取娃逻辑与 `/students` **同源**，不是「学生页有、看板故意不要」。  
- **方案**：  
  1. 增加 `loadError` / `loadStatus`；失败时空态改为「看板暂时打不开 · 重试」，禁止显示「去添加孩子」。  
  2. 首屏失败可降级 `GET /students` 做存在性提示：「已有孩子但摘要加载失败」。  
  3. 运行时核对：DevTools 看 `/dashboard/monitor` 是否非 200 / 业务错误（并确认占用 3000 的 API 是否为当前代码与同一 DB）。  
- **理由**：空态文案误导用户排错方向；与真实「零绑定」必须区分。

## 6. 与「看板显示添加孩子」的直接对照

| 假设 | 是否成立 |
|------|----------|
| 学生管理与看板读不同家长绑定表 | **否**，同源 |
| 没任务就不返回孩子 | **否**，无任务仍应有孩子卡 |
| 接口失败显示成「还没有孩子」 | **是，代码如此**（P0.3） |
| ≥1600 TV 模式导致「看不到孩子」 | **否**；TV 仍渲染孩子卡，只是交互变少。空态是 `children.length===0` |

**结论**：你现在测到的空态，优先按 **P0.3（加载失败/空数组误判）+ 运行中后端是否健康** 排查；不是「没布置任务」也不是学生管理假数据。
