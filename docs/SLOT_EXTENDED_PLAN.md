# P2 时段扩展档（可开关）+ 时钟映射可配

目标：丰富作息贴合度，**不绑架默认体验**；学生端继续「当前窗减负」。

状态：**已落地**

## 产品规则（来自教育向评审）

| 档 | 时段 | 默认 |
|----|------|------|
| **基础档** | 起床后 / 放学后 / 晚饭后 / 睡前 / 随时 | 始终可用 |
| **扩展档** | 上学前 / 早餐后 / 午餐后 | 家庭设置开关，默认关 |

- 发布页：按时段分组下拉，勿平铺一堆大按钮。
- 学生端仍只突出当前窗；枚举变多不改变「一屏少看见」。
- 时钟→时段映射可配置（高级），避免全国硬编码 14–18=放学后。

## 实现项

| ID | 项 | 说明 |
|----|-----|------|
| B1 | `TimeSlot` 增枚举 | `after_wake` + 扩展：`before_school` / `after_breakfast` / `after_lunch` |
| B2 | 迁移 `0016` | `family_settings.slot_extended_enabled`、`slot_clock_map`（JSON） |
| B3 | 设置读写 | DTO / `FamilySettings` / `toDto` / policy 合并进学生策略 |
| B4 | `today` / settings 下发 | `slotExtendedEnabled` + `slotClockMap`（已规范化） |
| F1 | `timeSlotPolicy` | 全序排名、`slotOrderForUi`、可配 `resolveCurrentSlot`、默认钟点表 |
| F2 | 家长休息日页 | 扩展档开关 + 各时段起止钟点（高级折叠） |
| F3 | 家长发布表单 | 选项随扩展档变化；基础档含「起床后」 |
| F4 | 学生今日 / 任务 Tab | 用家庭时钟映射与可见时段序 |
| T1 | 单测 | 钟点映射、扩展序、wrap（睡前跨夜） |

## 默认钟点（`[start, end)`，睡前可跨夜）

**基础档：**

| 时段 | 默认 |
|------|------|
| 起床后 | 6–9 |
| 放学后 | 14–18 |
| 晚饭后 | 18–21 |
| 睡前 | 21–6（跨夜） |
| 随时 | 未命中任一窗 |

**扩展档打开时叠加/收窄：**

| 时段 | 默认 |
|------|------|
| 起床后 | 6–7 |
| 早餐后 | 7–8 |
| 上学前 | 8–9 |
| 午餐后 | 12–14 |
| （其余同基础） | |

## 兼容

- 已有任务 `after_school` 等不变。
- 关掉扩展后：已选扩展时段的任务仍可展示/完成，发布下拉不再提供新选项。
- 排名始终用**全量时序**，避免扩展任务排序错乱。

## 非目标

- 不强制「未到点不能做」
- 不按类别自动改时段（仅文案建议可二期）
- 不做分钟级精度（整点足够）
