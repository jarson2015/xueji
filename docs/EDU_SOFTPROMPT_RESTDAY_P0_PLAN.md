# 学迹 · 休息日自愿 SoftPrompt 收口（P0）

承接学生约定/兑换 SoftPrompt 非目标中的「休息日拿到今日、建生默认 demo1234」。  
原则：**休息日先不催、自愿可做；敏感建生与删任务同一商量语气；不扫批量运维与退出登录。**

状态：**已落地**

---

## 方向理由

| 理由 | 说明 |
|------|------|
| 教育主叙事 | Today 已是「休息日，先不催」；任务档案仍用冷框问「仍想去做吗」，语气审讯感 |
| 孩子触点 | 休息日每周可遇，是教育 SoftPrompt 主路径最后一块缺口 |
| 对称卫生 | 重置密码已不预填弱密；建生仍默认 `demo1234` 同页割裂 |
| 后果明确 | 单条删任务「孩子立刻看不到」，值得 SoftPrompt；批量仍属运维 |
