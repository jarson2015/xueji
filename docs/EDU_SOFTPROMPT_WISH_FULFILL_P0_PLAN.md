# 学迹 · 家长愿望兑现 SoftPrompt（P0）

承接学生兑换 SoftPrompt、本页已有「先缓缓」SoftPrompt。  
原则：**兑现路径同一商量语气；互助卡≠买免做；多件家务用芯片点选，不用序号硬框；不扫批量运维。**

状态：**已落地**

---

## 方向理由

| 理由 | 说明 |
|------|------|
| 对称 | 学生兑换已 SoftPrompt；家长兑现仍 `ElMessageBox`/`prompt`，语气断档 |
| 教育 | 互助卡核心叙事「先缓缓一件家务 / 免做不是责任消失」应落在软确认 |
| 体验 | 多件家务输入序号 1-N 对家长不友好；芯片点选更贴合现有 SoftPrompt 模式 |

---
