# 学迹 · 学生约定与兑换 SoftPrompt（P0）

承接家长侧约定 SoftPrompt、学生管理 SoftPrompt。  
原则：**孩子日常关键路径同一商量语气；积分不是钱 / 说到做到 / 交由家长保管；不扫全站。**

状态：**已落地**

---

## 方向理由

| 理由 | 说明 |
|------|------|
| 对齐家长轨 | 家长约定还回/结束已 SoftPrompt；学生借出/心意/还回仍冷弹窗，语气断档 |
| 教育叙事 | 文案本就在讲「积分不是钱」「心意≠借贷」「说到做到」；应落在软确认而非 Element 硬框 |
| 高风险决策 | 兑换扣分前含互助卡与约定未还提醒，最需要温和护栏 |
