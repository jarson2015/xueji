# 教育设置「常用 / 进阶」瘦身 · P0

## 开发理由

1. **问题**：`FamilyEduView` 一屏瀑布（预设 → 积分多开关 → 作息 → 公约 → 零花 → 约定），首次进入认知负担大，常用项被淹没。
2. **目标**：首屏只见「策略包 + 加分节奏 + 年龄段 + 作息开关」；反思/缓做/自动确认/公约默认收在「进阶」；零花与积分约定保持现有开关+折叠。
3. **非目标**：不改 API/字段；不删能力；不改 More 入口路由。

## 范围

| 区 | 内容 |
|----|------|
| 常用 | 预设卡片；少比分；加分节奏（含 fade 提示）；年龄段；扩展时段 + 钟点折叠 |
| 进阶（默认收起） | 反思小问；今日缓做件数；每晚自动确认；公约两段文案 |
| 保持 | 零花钱约定、积分约定与赠予（已有总开关+折叠） |

## 验收

- [x] 首屏无反思/缓做/自动确认/公约正文（须展开进阶）
- [x] 若已开启自动确认，进入页时自动展开「打卡与确认」
- [x] 保存行为与字段不变；`npm run build` 通过
