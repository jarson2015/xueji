# 学生「我想加一件」靠近今日 · P0

## 开发理由

1. **问题**：任务提议只在 `MeView`（我的计划），孩子日常主路径是「今日」；自主感闭环（提 → 家长看板待处理）入口过深。
2. **目标**：今日页在「下一件 / 主题」附近增加**轻入口**；抽屉内提交（复用 `POST /tasks/propose`）；TV 不展示（大屏只看下一件）。
3. **非目标**：不删 Me 完整表单；不改 API；不把完整表单塞进首屏卡片。

## 范围

| 项 | 说明 |
|----|------|
| 轻条 | 今日：主题卡下方「我想加一件小事」；有待审时显示一句状态 |
| 抽屉 | 标题 / 主题 chips / 类型 / 分钟 / 交给家长；`--drawer-phone` |
| 空态 | 休息日/做完：主 CTA 可开提议抽屉；次要仍去计划/愿望 |
| Me | 保留原表单；一句「也可在今日提」 |

## 验收

- [x] 非 TV 今日可见轻入口；抽屉可提交
- [x] Me 仍可提；`npm run test:unit` + `build` 通过
