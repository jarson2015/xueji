# 家长任务清单 · UX 布局 P1 开发计划

承接全站布局规划中，学生今日（P0）之后的 **配置主路径**。  
原则：**已发布优先；模板降权；平板/桌面少开遮罩抽屉；对照编辑**。

状态：**已落地**（2026-07-14）

---

## 为何是 P1

| 因素 | 说明 |
|------|------|
| 频率 | 家长底栏第二 Tab；从看板「去任务清单」高频跳入 |
| 痛点 | 模板块压在列表上；≥768 宽屏仍用抽屉盖住列表，无法边看边改 |
| 科学 | 主从对照（master–detail）降低工作记忆负荷；配置页目标是「管家底」不是「逛模板墙」 |

---

## 信息层级（P1 后）

```
页头（任务清单 + 发布）
→ 紧急：孩子提议（若有）
→ 软提示（密度 / 首周）
→ 【主】已发布筛选 + 列表
→ 【次】从模板添加（默认折叠；空列表可引导展开）
→ 【平板 / 桌面】右侧常驻编辑区（手机 / TV 仍用抽屉）
```
